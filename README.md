# Dataset Preparation and Exploratory Data Analysis

## Overview
This project inspects, cleans and prepares the Titanic dataset for future machine learning work.

## Dataset
- **Name:** Titanic Passenger Dataset
- **Source:** [Seaborn Titanic CSV](https://raw.githubusercontent.com/mwaskom/seaborn-data/master/titanic.csv)

## Work Performed
- Dataset inspection and data types
- Missing-value handling
- Duplicate and consistency checks
- Exploratory data analysis and visualisations
- Categorical encoding
- Numerical feature scaling
- Export of the prepared dataset

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn and Scikit-learn.

## Files
- `Activity1.ipynb` - notebook containing the analysis and preparation steps
- `data/titanic_prepared_dataset.csv` - prepared dataset generated by running the notebook
- `requirements.txt` - required Python libraries

## Run the Notebook
Install the libraries:

```bash
pip install -r requirements.txt
```

Open `Activity1.ipynb` in Jupyter Notebook or Google Colab and run all cells from top to bottom. The final cell creates `titanic_prepared_dataset.csv`. Move that file into the `data/` folder before committing if you want to keep the repository structure shown above.
